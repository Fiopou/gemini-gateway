# Что изменено

## Исправления

- SSE теперь разбирает CRLF/LF, многострочные `data:` и корректно закрывает upstream-response. Неожиданное закрытие потока без `[DONE]` считается ошибкой, а не успешным завершением.
- Потоковые upstream-ошибки больше не отбрасываются незаметно; CLI также отображает ошибку потока.
- Закрываются HTTP-ответы и на обычном, и на потоковом пути; ошибки чтения/некорректный JSON upstream преобразуются в понятные `GatewayError`.
- Оценка контекста больше не округляет каждое короткое сообщение вниз до нуля; использует сериализованный UTF-8 размер и запас на сообщение.
- Резюмирование истории сохраняет системные/developer-инструкции и последние сообщения, не отбрасывает начало истории только потому, что она длиннее одного чанка. Слишком большие истории не укорачиваются молча.
- Если `GATEWAY_MAX_CONTEXT` не соблюдён даже после резюмирования, запрос останавливается с `413`. Интерактивный режим тоже не отправляет его и не теряет предыдущую историю.
- JSON-тело валидируется: тип верхнего объекта, `messages`, `role`, `content`, `stream` и размер запроса проверяются до обращения к upstream.
- SSE обрабатывает `Retry-After`, а дневная квота рассчитывается до следующей полуночи Pacific Time. Добавлен fallback для Windows без IANA timezone database.
- Удалены дубли ключей из пула; повторный API-ключ не считается независимым проектом.
- `gemini-3.7-flash` исключён из автоматического каскада из-за перенаправления на `gemini-3.8-flash`; ID всё ещё доступен для ручного выбора.
- `/v1/models` больше не содержит дублированные ID и не перечисляет человекочитаемые алиасы как будто это реальные модельные ID.
- По умолчанию сервер привязывается к `127.0.0.1`; CORS не отражает произвольный интернет-origin; размер тела ограничен 10 MiB.
- Стартовый probe теперь выключен по умолчанию, чтобы сервер не расходовал квоту сразу при запуске.
- Команда `models` работает без API-ключей.

## Регрессионные тесты

Добавлен `tests/test_gateway.py`: 26 тестов для SSE, квот и ротации ключей, compaction, CORS, авторизации, валидации запросов, ограничения размера тела, списка моделей и HTTP-стриминга. Весь набор пройден в изолированной среде без вызовов Google API.
